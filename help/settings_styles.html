Themes

Configure all interface, chat, log, transfer and user-match fonts and colors under Appearance > Themes. Your current appearance is loaded as a custom theme. The table labels display their configured text colors and backgrounds. Single-color interface entries use their configured color for the label with a contrasting backdrop. Select an item to edit its font, text color, background and text effects. Changes remain in the settings draft until you click OK; Cancel discards them.

Mode and theme files

Choose Follow Windows, Light or Dark. The interface palette is used in Dark mode; Windows high contrast takes precedence for interface colors. Select a theme to load its complete appearance. Existing palette-only themes derive chat colors from their palette.

Save theme exports the draft to an XML file. Import theme validates a file and loads it into the draft. Save in the per-user Themes folder to add a preset; Open folder and Reload themes manage the preset list. Files in this folder override application themes with the same filename.

Theme XML version 2 includes the interface palette, fonts, content colors and user-match appearance. Files are UTF-8 XML, limited to 64 KiB. Matching rules and ignore behavior remain in Styles / User matching.

General

Global application style

The style used throughout all DC++ windows.

Transfers

Uploads

The style used to paint upload transfer bars. Default background color: RGB(205, 60, 55).

Downloads

The style used to paint download transfer bars. Default background color: RGB(55, 170, 85).

Chat

Links

The style used to display clickable links in chat. A default value is generated when DC++ is started, based on the global text color.

Logs

The style used to display chat logs that show up in new chat windows, assuming there is a relevant chat history to be found. A default value is generated when DC++ is started, based on the global text color (DC++ tries to make it look more grey).

Users

The appearance of users that match definitions. Theme files associate these styles with exact definition names without changing matching rules. A definition absent from an imported theme inherits its appearance. Edit definitions in Styles / User matching.

Live chat preview

The preview uses an actual RichEdit control and the same renderer as chat. It shows the selected style and sample incoming and outgoing messages, timestamps, nicknames, mentions, links, system messages and history. Editing the preview does not change active chat settings.

Font customization

By default, the font used by the current Windows theme is used throughout DC++ (generally Segoe UI (size 9) on Windows 7 and newer). A different font may be selected here, including bold, italic, underline and strikethrough. Text effects adds underline and strike variants, subscript/superscript, capitalization, outline, shadow, character spacing, baseline offset and kerning. Advanced effect rendering depends on the Windows RichEdit version; the preview shows the local result. Other controls use the font properties they support.

Text effects dialog

Text effects sits beside Select font. Its live RichEdit preview updates as you check bold, italic, underline, strikethrough, capitalization, script, outline and shadow options. Choose the underline pattern from the dropdown. Double strikethrough overrides single; turning it off restores the previous single-strike choice. Subscript/superscript and small/all capitals are mutually exclusive.

Character spacing, baseline offset and kerning use points. Positive baseline offsets raise the text; negative values lower it. Reset effects restores normal text. OK accepts the draft and Cancel discards it; the theme is applied when the main Settings dialog is accepted.

Text color customization

By default, the text color is taken from the current Windows theme (generally black). A different text color may be configured here.

Background color customization

By default, the background color is taken from the current Windows theme (generally white). A different background color may be configured here.

Configure user matching definitions

Switch to the User matching settings page.

Show those generated by DC++

Select whether the list should display user matching definitions that DC++ has automatically generated (for example to ignore users). These definitions may clutter the view so they are hidden by default.
